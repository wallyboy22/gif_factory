      if ($?) { python scripts/sync_fire_col5.py }

-----------------------------------------------------------------
  2. BIOMAS (7 territórios, 23 produtos)
-----------------------------------------------------------------

  Pampa, Pantanal + mosaico "Biomas".

  Comando:
      python scripts/run_fire_col5_biomes.py --workers 8 --resume

-----------------------------------------------------------------
  3. REGIÕES (9 territórios, 23 produtos)
-----------------------------------------------------------------

-----------------------------------------------------------------
  4. ESTADOS / UFs (28 territórios, 23 produtos)
-----------------------------------------------------------------
  Gera GIFs para todos os 26 estados + Distrito Federal.

  Comando:
      python scripts/run_fire_col5_ufs.py --workers 8 --resume

-----------------------------------------------------------------
  5. TUDO DE UMA VEZ (35 territórios, 23 produtos)
-----------------------------------------------------------------
  Gera GIFs para Brasil, biomas e estados em uma execução.

  Comando:
      python scripts/run_fire_col5_batch.py --workers 8 --resume

-----------------------------------------------------------------
  6. SINCORNIZAR DADOS (upload GCS + índices)
-----------------------------------------------------------------
  Sobe para o GCS o que ainda não foi enviado, reconstrói o
  index.json e gera os CSVs do Looker Studio.

  Comando:
      python scripts/sync_fire_col5.py

  Opções:
      --dry-run      Só mostrar o que seria feito, sem enviar
      --skip-upload  Pular upload, só rebuildar índices

-----------------------------------------------------------------
  FLUXO RECOMENDADO
-----------------------------------------------------------------
  1. Rodar os grupos desejados (ex: biomas + ufs)
  2. Rodar sync ao final de cada grupo (ou no final de tudo)

  Exemplo completo:
      python scripts/run_fire_col5_biomes.py --workers 8 --resume
      python scripts/sync_fire_col5.py

      python scripts/run_fire_col5_ufs.py --workers 8 --resume
      python scripts/sync_fire_col5.py
